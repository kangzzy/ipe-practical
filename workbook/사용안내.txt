정보처리기사 실기 · HTML 문제집

1. 정보처리기사_실기_문제집.html 파일을 Chrome 또는 Edge에서 엽니다.
   이 HTML 한 파일에 문제·해설·개념·화면 기능이 모두 포함되어 있습니다.
   자체 제작 문제는 인터넷 없이 풀 수 있으며, 사이트 링크를 열 때만 인터넷이 필요합니다.

2. 구성
   - 10개 과목, 79개 상세분류
   - 기본 237문항: 상세분류마다 독립적으로 작성한 3문항
   - 추가 변형 120문항: 포인터, 진법, 비트 연산, 서브넷, FCFS, SQL 집계 각 20문항
   - 실전 심화 24문항: C·Java·Python 각 8문항, 복합 코드 추적 및 단계별 해설
   - 총 381문항: 전부 자체 제작이며 실제 기출로 표시하지 않습니다.
   - 문제별 정답, 상세 풀이, 실수 방지, 연결된 개념 노트
   - 선택된 계산·코드 문제에는 추적표와 중간 결과표 포함
   - 문어CBT 21회차, 정처LAB 11회차 원문 링크
   - 문어CBT 79개 개념별 링크, 두 사이트 연습문제 진입 링크
   - 정처LAB과 문어CBT 같은 연도·회차는 범위가 겹칩니다.
   - 사이트의 모든 개별 문항을 상세분류한 것은 아닙니다. 기출은 회차 링크,
     과목별 연결은 개념·연습 진입 링크입니다. 일부 원문 기능은 유료/로그인이 필요합니다.

3. 권장 사용 순서
   과목 선택 → 상세분류 선택 → 답안 작성 → 정답·해설 보기 → 맞음/틀림/헷갈림 표시
   “복습 조건”에서 틀림+헷갈림만 다시 풀 수 있습니다.
   개념 노트에서 “관련 문제 풀기”를 누르면 해당 상세분류 문제로 이동합니다.
   분류는 문어CBT 로드맵의 2026-10-21 확인 결과를 기준으로 합니다.

4. 기록 저장
   답안·채점·북마크는 현재 브라우저의 로컬 저장소에 저장합니다.
   파일 위치나 브라우저를 바꾸거나 브라우저 데이터를 지우면 기록이 보이지 않을 수 있습니다.
   공부가 끝날 때 “학습 기록 내보내기”로 JSON 백업을 만드세요.
   다른 환경에서 파일을 열고 “학습 기록 불러오기”로 복원할 수 있습니다.
   자동 채점은 하지 않습니다. 정답과 해설의 의미를 비교하여 직접 채점하세요.

5. 인쇄와 자료
   개념 노트에서 과목을 선택하고 “현재 화면 인쇄 / PDF”를 누르면 해당 개념이 펼쳐져 출력됩니다.
   문제 화면의 인쇄는 현재 문항과 해설입니다. 문제 화면 전체 381개 일괄 인쇄 기능은 없습니다.
   questions.json은 전체 문제·개념·링크의 원본 데이터입니다.
   content-*.js / build.js / template.html은 수정 가능한 제작 소스입니다.
   재생성: 이 폴더에서 node build.js
   내용 검사: python verify.py

6. 검증 범위
   문제 수·분류·ID·문제 중복 검사, Python 예제 실행, SQL 공통 동작 실행,
   추가 계산 문제 검증을 수행했습니다. 상세 결과는 verification.json에 있습니다.
   C/Java 컴파일러가 없어 이 언어의 예제는 직접 컴파일하지 못했습니다.
   자체 제작 학습 자료이며 공식 기출, 공식 채점 기준, 출제 범위 전체를 보장하는 자료는 아닙니다.
   개념 노트는 요약과 예제 중심입니다. 넓은 상세분류 안의 모든 하위 개념을 망라하지는 않습니다.
